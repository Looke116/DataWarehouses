This is a university project 

If you want to run this project I'd suggest using an IDE, I'm using IntelliJ.
You are going to need API keys from Alpha Vantage, Twelve Data and Mistal AI.
The first two go in a file named `apikey` the root of the project and it has to be formated like this `AlphaVantage:you_api_key`.
The Mistal API key goes in application.properties or if you can make it work as an environment variable.
You are going to need MongoDB and Apache Spark as well.
